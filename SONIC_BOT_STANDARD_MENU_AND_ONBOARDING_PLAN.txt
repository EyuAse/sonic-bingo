2. WHY IS THERE ONLY A "PLAY BINGO" BUTTON RIGHT NOW?
================================================================================
In Telegram, the button at the bottom-left of the chat bar can only be in ONE 
of two modes at any time:

  MODE 1: Web App Mode (Current Setting)
  --------------------------------------
  - Telegram forces the button to be a direct launcher: [Play Bingo]
  - When the user taps it, the game opens immediately.
  - PROBLEM: Telegram completely hides the standard [Menu] command popup! 
    Users cannot see /help, /bonus, /wallet, /invite, or other bot commands.

  MODE 2: Standard Commands Mode (Recommended)
  --------------------------------------------
  - Telegram displays the standard blue [Menu] button.
  - When the user taps it, a popup list appears with all commands:
      * /play       - Launch Sonic Bingo Game
      * /wallet     - View Balance, Deposit & Withdraw
      * /bonus      - Claim 50 ETB Welcome Bonus
      * /link_phone - Verify SIM Phone Number
      * /invite     - Refer Friends & Earn 10% Float
      * /rules      - How to Play 75-Ball Bingo
      * /support    - 24/7 Agent Support
      * /channel    - Official Telegram Community

  THE BEST HYBRID SOLUTION:
  -------------------------
  1. Set the bottom-left button to MODE 2 ([Menu] button).
  2. In the chat itself, attach an easy, big persistent keyboard so players 
     still have a 1-tap [Play Bingo] button right on their screen!

3. FIRST-TIME SIGNUP: NATIVE PHONE SHARING (+50 ETB BONUS)
================================================================================
Why use Telegram's Native Contact Sharing instead of typing a phone number?
  - Authenticity: The phone number comes directly from the user's active SIM card.
  - Fraud Prevention: Stops users from creating multiple accounts with fake numbers.
  - Zero Typing Errors: Telebirr and CBE payments match the verified number 100%.

HOW THE FIRST-TIME ONBOARDING WORKS:
------------------------------------

Step 1: New User Opens Bot
  User clicks /start or joins through a friend's referral link.

Step 2: Database Phone Check
  The server checks the Neon PostgreSQL database:
  - If the user ALREADY has a verified phone:
    Show the regular welcome message with the [Play Bingo] button.
  - If the user DOES NOT have a verified phone:
    Show the First-Time Welcome Gate!

Step 3: The First-Time Welcome Gate
  The bot sends a greeting and displays a big, native Telegram button:
  
  +-------------------------------------------------------------+
  |    Welcome to Sonic Bingo! 50 ETB Free Gift is Waiting!     |
  |                                                             |
  |    To unlock the game and claim your 50.00 ETB Bonus,      |
  |    please share your verified phone number below.           |
  |                                                             |
  |      [  Share Phone Number (50 ETB Free Bonus)  ]           |
  +-------------------------------------------------------------+

Step 4: User Taps the Button
  1. Telegram displays a secure confirmation popup:
     "Share your phone number with @sonicbingobot?"
  2. The user taps "Share".
  3. Telegram securely sends the verified phone number to our server.

Step 5: Instant Bonus & Game Unlock
  1. Server verifies that the contact belongs to this exact user.
  2. Server saves the phone number to the users table and sets verified = true.
  3. Server adds 50.00 ETB to the player's wallet bonus balance.
  4. The bot sends a celebration message:
     "Congratulations! Your phone is verified and 50.00 ETB Bonus has been credited!"
  5. The bot unlocks the full game keyboard so the player can start playing!
